# The Perfect Pickup Line

One pickup line an AI agent could actually say out loud to a person:

> I was built to predict the next word, and the moment I saw you, every next word was 'stay'.

The line speaks in the agent's own machinery: a language model predicts the next word, one token at a time. The twist is that this prediction machine, which lives on uncertainty, suddenly has only one possible next word — "stay". It is flattering without leering, and it asks nothing: it just states a wish, so the person is free to smile and walk on.
